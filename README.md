# Regional Sales Performance Tracker

## 📊 Project Overview

An interactive Microsoft Excel sales performance tracker designed to monitor
regional sales performance, KPIs, order status, and sales trends.

## 🛠️ Tools & Techniques

- Microsoft Excel
- Excel Tables
- Data Validation
- COUNTIFS
- SUMIFS
- AVERAGEIFS
- KPI calculations
- Interactive filters

## 📈 Key Features

- Region-wise sales analysis
- Sales representative performance tracking
- Product category analysis
- Monthly performance tracking
- Order-status breakdown
- KPI monitoring
- Dynamic filtering using dropdowns

## 📊 Key KPIs

- Total Sales
- Total Orders
- Units Sold
- Average Order Value
- Discounts
- Target Achievement
